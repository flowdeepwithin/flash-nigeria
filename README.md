# Flash Nigeria

Breaking Nigeria. Every second. - https://www.flashnigeria.com

Nigerian breaking-news and intelligence platform: Flash News, Flash Trends, Flash Intelligence (48-hour search), Flash Voice, My Flash and Flash PRO.

## Structure
- index.html - the whole app (layout, styles and scripts)
- api/news.js, api/image.js, api/og.js - Vercel serverless functions
- manifest.json, icons/ - installable web app (PWA) settings
- sitemap.xml, vercel.json - SEO and hosting config

Note: main.css, app.js and sw.js are older files that index.html does not load.
